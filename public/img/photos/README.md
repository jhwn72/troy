# Photos for the chat bubbles

Drop these four files in this folder. The landing page picks each one up by itself when it exists and
shows the drawn placeholder when it does not.

| File | Shown in | Shape on the page |
|---|---|---|
| `airpods.webp` | Lost and found, the finder's photo of the AirPods | 4:3 (landscape) |
| `food-trays.webp` | Free food, the club officer's photo of the trays | 4:3 (landscape) |
| `door-broken.webp` | Broken things, the student's photo of the door | 3:4 (portrait) |
| `door-fixed.webp` | Broken things, the technician's photo of the fixed door | 3:4 (portrait) |

Export as WebP, about 900px on the long side. Photos are cropped to fill the bubble, so keep the subject near the middle.

Anything else in this folder is ignored, and the names must match exactly.
